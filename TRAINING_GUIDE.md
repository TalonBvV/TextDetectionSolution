# PatchFormer Training Guide

This guide explains how to use the dataset generation pipeline with the PatchFormer model.

## Quick Start

### 1. Generate Dataset
```bash
cd DatasetGeneration
pip install -r requirements.txt
python gen_dataset.py --output_dir ../dataset --run-all
```

### 2. Train Model
```bash
cd TextDetection
python train.py --dataset-dir ../dataset/final --use-v2-loss --epochs 100
```

## Complete Workflow

### Step 1: Generate Training Data

The `DatasetGeneration` pipeline downloads, converts, augments, and finalizes text detection datasets:

```bash
# Full pipeline (downloads all datasets, converts, augments 2x, finalizes)
python gen_dataset.py --output_dir ./dataset --run-all

# Specific datasets only
python gen_dataset.py --output_dir ./dataset --run-all --datasets hiertext cord

# Quick test with limited samples
python gen_dataset.py --output_dir ./dataset --run-all --max-samples 100 

# Higher augmentation (3x)
python gen_dataset.py --output_dir ./dataset --run-all --augmentation 3.0
```

**Output Structure:**
```
dataset/final/
├── train/
│   ├── images/      # RGB images (≥1024px)
│   ├── masks/       # Binary PNG (0=bg, 1=text)
│   ├── instances/   # Instance PNG (unique ID per word)
│   └── polygons/    # JSON with coordinates
├── val/
├── test/
├── manifest.json
└── splits.json
```

### Step 2: Train Model

The training script supports the unified dataset format:

```bash
# Basic training (legacy loss)
python train.py \
    --dataset-dir ./dataset/final \
    --epochs 100 \
    --batch-size 4 \
    --lr 1e-4

# Full V2 training (with affinity, vertex, DB losses)
python train.py \
    --dataset-dir ./dataset/final \
    --use-v2-loss \
    --epochs 100 \
    --batch-size 4

# With mixed precision for faster training
python train.py \
    --dataset-dir ./dataset/final \
    --use-v2-loss \
    --mixed-precision \
    --epochs 100

# Test with dummy data
python train.py --use-dummy-data --epochs 5
```

## Training Arguments

| Argument | Default | Description |
|----------|---------|-------------|
| `--dataset-dir` | None | Path to unified dataset (from DatasetGeneration) |
| `--variant` | small | Model variant: tiny, small, base |
| `--num-classes` | 2 | Number of classes (2 for text detection) |
| `--input-size` | 1024 | Input image size |
| `--epochs` | 100 | Number of epochs |
| `--batch-size` | 4 | Batch size |
| `--lr` | 1e-4 | Learning rate |
| `--use-v2-loss` | False | Use full V2 loss (affinity, vertex, DB) |
| `--mixed-precision` | False | Use mixed precision (FP16) |
| `--checkpoint-dir` | checkpoints | Checkpoint directory |
| `--log-dir` | logs | TensorBoard log directory |

## Loss Functions

### Basic Loss (`PatchFormerLoss`)
- Segmentation loss (Dice + BCE)
- Token classification loss
- Reconstruction loss (MAE pretraining)
- Contrastive loss

### V2 Loss (`PatchFormerV2Loss`) - Recommended
All basic losses plus:
- **Affinity loss**: Supervises feature propagation between instances
- **Vertex loss**: Supervises polygon corner detection
- **DB loss**: Supervises differentiable binarization for sharp outputs
- **Initial segmentation loss**: Intermediate supervision

Use `--use-v2-loss` to enable full pipeline supervision.

## Data Format Requirements

The training code expects:

| Component | Format | Generated By |
|-----------|--------|--------------|
| **Images** | RGB JPEG/PNG, ≥1024px | dataset_finalize.py |
| **Masks** | 8-bit PNG, 0=bg, 1=text | dataset_merge.py |
| **Instances** | 16-bit PNG, unique IDs | dataset_merge.py |
| **Polygons** | JSON with coordinates | dataset_merge.py |

### Instance Maps (for Affinity Loss)

Instance maps provide unique IDs for each text word/region. This enables the affinity loss to learn which pixels belong together, improving:
- Word-level segmentation accuracy
- Separation of adjacent text
- Instance-aware feature propagation

## Two-Phase Training

The model uses two-phase training:

### Phase 1 (Epochs 1-30): Representation Learning
- Higher reconstruction weight (0.3)
- Higher masking ratio (0.75)
- Focus: Learn good visual representations

### Phase 2 (Epochs 31+): Segmentation Fine-tuning
- Lower reconstruction weight (0.1)
- Lower masking ratio (0.5)
- Focus: Optimize for text detection

Configure in `TrainingConfig`:
```python
phase1_epochs: int = 30
phase2_reconstruction_weight: float = 0.1
phase1_mask_ratio: float = 0.75
phase2_mask_ratio: float = 0.5
```

## Monitoring Training

### TensorBoard
```bash
tensorboard --logdir ./logs
```

Tracked metrics:
- `train/total`: Total training loss
- `train/segmentation`: Main segmentation loss
- `train/affinity`: Affinity loss (V2)
- `train/vertex`: Vertex loss (V2)
- `train/db_*`: DB losses (V2)
- `val/iou`: Validation IoU
- `val/dice`: Validation Dice score
- `val/boundary_f1`: Boundary F1 score

### Checkpoints
Saved to `--checkpoint-dir`:
- `checkpoint_epoch_*.h5`: Periodic saves
- `best_model.h5`: Best validation IoU
- `final_model`: Final weights

## Troubleshooting

### Memory Issues
- Reduce `--batch-size`
- Use `--mixed-precision`
- Reduce `--input-size`

### Slow Training
- Use `--mixed-precision`
- Increase batch size if GPU memory allows
- Use smaller model variant (`--variant tiny`)

### Missing Instance Maps
If you see warnings about missing instance maps:
```
Note: instance_map not found, using segmentation for affinity loss
```
This is handled gracefully - the loss falls back to using binary masks.

### Dataset Not Found
Ensure dataset structure is correct:
```
dataset_dir/
├── train/
│   ├── images/
│   ├── masks/
│   ├── instances/
│   └── polygons/
└── val/
    └── ...
```

## Example: Full Training Run

```bash
# 1. Generate dataset (takes several hours)
cd DatasetGeneration
python gen_dataset.py \
    --output_dir ../dataset \
    --run-all \
    --datasets hiertext cocotext textocr cord

# 2. Train model
cd ../TextDetection
python train.py \
    --dataset-dir ../dataset/final \
    --variant small \
    --use-v2-loss \
    --mixed-precision \
    --epochs 100 \
    --batch-size 4 \
    --checkpoint-dir ./checkpoints \
    --log-dir ./logs

tensorboard --logdir ./logs
```
